# Architecture Decision Records

Architecture Decision Records capture accepted internal technical decisions whose consequences extend beyond one pull request but do not require a public ecosystem RFC.

## Naming

Use sequential files:

```text
0001-short-decision-title.md
0002-next-decision.md
```

## Status

Each ADR uses one of:

- Proposed
- Accepted
- Superseded
- Rejected
- Deprecated

## Required sections

- Title
- Status
- Date
- Context
- Decision
- Consequences
- Alternatives considered
- Related records

Accepted ADRs are not silently rewritten. Material changes require a new ADR that supersedes the old record.

See `docs/governance/ADR_PROCESS.md` for the full process.
