Welcome to the public Vii documentation.

Vii is a framework-neutral TypeScript ecosystem centered on explicit reactive state, lifecycle ownership, diagnostics, and small composable application primitives.

## Start here

If this is your first time using Vii, begin with [Getting Started](/docs/getting-started/).

The guide covers the current Core acquisition status, State, subscriptions, Computed values, Batch updates, Scope ownership, and deterministic disposal without assuming that unpublished packages are available from npm.

## Current documentation scope

The public documentation is being built incrementally alongside the Vii runtime. Content appears here only when the corresponding implementation or accepted architecture is mature enough to document without inventing behavior.

At the current stage, Core primitives are experimental, `@vii-labs/core` is not yet published to npm, and framework adapters, CLI, Form, Query, HTTP, Schema, and Flow remain subject to their own maturity and availability boundaries.
