# Design sources

New System Design work stores editable diagrams in `docs/designs/<task-slug>/`.

Follow [System Design First](../architecture/SYSTEM_DESIGN_GUIDELINES.md). Choose Excalidraw, draw.io, Mermaid or a combination according to the task; do not create placeholder files for unused formats.

- Excalidraw: `name.excalidraw` + `name.svg`
- draw.io: `name.drawio` + `name.svg`
- Mermaid: `name.mmd` or a fenced diagram in `DESIGN.md`; SVG optional

Keep the design's approval evidence and relevant RFC/ADR links in `DESIGN.md`. Existing accepted designs under `docs/architecture/designs/` remain valid; link them rather than duplicating content.
